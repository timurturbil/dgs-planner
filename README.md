# DGS Plan

DGS 2027 çalışma ve yaşam programı (React + Vite, PWA, veriler telefonda localStorage'da).

```bash
npm install
npm run dev     # aynı Wi-Fi'deki telefondan da açılır
npm run build
```

Vercel: projeyi içe aktar → Framework "Vite" otomatik seçilir, ek ayar gerekmez.
Telefonda: Safari ile aç → Paylaş → "Ana Ekrana Ekle".
